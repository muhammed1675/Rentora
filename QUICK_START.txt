STEP 1: Add Missing Environment Variables to Vercel
────────────────────────────────────────────────────

Go to: Vercel Project > Settings > Environment Variables

Add these TWO critical variables if missing:

  1. SUPABASE_SERVICE_ROLE_KEY
     - Get from: Supabase Dashboard > Settings > API > Service Role Key
     - This key is required for email notifications to work!
     
  2. SUPABASE_URL  
     - Get from: Supabase Dashboard > Settings > API > Project URL
     - Should look like: https://xxxxxxxx.supabase.co

Verify these are ALSO present:
  - REACT_APP_SUPABASE_URL
  - REACT_APP_SUPABASE_ANON_KEY
  - FLW_SECRET_KEY
  - REACT_APP_FLW_PUBLIC_KEY
  - FLW_WEBHOOK_HASH

STEP 2: Verify Flutterwave Webhook Configuration
────────────────────────────────────────────────

Go to: Flutterwave Dashboard > Settings > Webhooks

Set URL to: https://your-production-domain.vercel.app/api/flutterwave-webhook

Secret Hash: Must match FLW_WEBHOOK_HASH in Vercel (should already be set)

STEP 3: Deploy
────────────

Push to your repository or deploy manually:
  $ vercel deploy --prod
